About the artwork and the movement experiment
THE MECHANIC

Equal speed in every direction.

Diagonal input is normalized. Movement runs at 180 pixels per second, with a 50 ms frame cap. Switching artwork changes only the drawing.

Read the investigation ↗
THE ARTWORK

One scene. One visual language.

DreamLayer generated the courtyard, then a matching sheet of six objects from that reference. Background removal and crops turned the sheet into game assets. No account is needed to play.

See the asset workflow ↗
THE BOUNDARY

A controlled demonstration.

REA analyzed our minified reference game. This is one bounded movement investigation. Patrols, shields and the pulse are original game rules built around that movement.
